# CakePHP Prompts Plugin

The **Prompts** plugin wraps [Laravel Prompts](https://laravel.com/docs/prompts) for CakePHP Console applications.

It provides TTY-friendly forms and inputs including text, select, multiselect, confirm, search, progress, and related helpers, with fallbacks to CakePHP `ConsoleIo` prompts when a rich terminal is unavailable.

## Requirements

* PHP 8.2+

See [Versions.md](docs/Versions.md) for the supported CakePHP versions.
